# Tailoring a CV

## Input
1. **The current CV** — ask for the file if there is none. (Read
   `kariyer/cv-ana.md` if it exists.)
2. **The posting** — take the link and read it. If you cannot reach it, ask for
   the text.

Do not start without both.

## 1. Decode the posting
Extract and list:
- **Required** qualifications (must-have)
- **Preferred** qualifications (nice-to-have)
- The **words that repeat** in the posting — the company's own language, which
  you will carry into the CV
- Quiet signals: "fast-paced", "will build from scratch", "comfortable with
  ambiguity" → the way of working they are looking for

## 2. Match — honestly
```
| Requirement | Do they have it | Evidence | What to do |
```
Three outcomes: **Has it, with evidence** · **Has it, but it is invisible on the
CV** · **Does not have it**

**Never invent the missing ones.** Say plainly how many are missing. If more than
half the required ones are absent, say that up front — whether it is worth
applying is the user's call, but they should make it knowing.

## 3. Tailor
- **Ordering:** the experience most relevant to the posting goes to the top. Same
  content, different order.
- **Language:** use the posting's own terms (if it says "veri analizi", do not
  write "data analytics"). ATS filters match on words.
- **Bullet structure:** `<action verb> + <what you did> + <measurable result>`.
  If a result carries no number, work out why; if there genuinely is none, write
  the effect instead.
- **Shorten** irrelevant bullets rather than deleting them — gaps look bad.
- One page (student or junior) or two (5+ years). More than that does not get
  read.

## 4. Deliver
- The tailored CV file (`.docx` or `.pdf`, whichever was asked for)
- **A list of changes:** what moved, what was rewritten, what was shortened
- **The gaps that could not be closed**, and how they might be compensated for
  (a side project, a certificate, an explanation in the cover letter)

## Rules
- **Never write experience the person does not have.** An inflated CV collapses
  in the interview.
- No cliché adjectives: "detail-oriented", "team player", "fast learner" — these
  carry no information; put evidence there instead.
- Turkish posting → Turkish CV, English posting → English CV.
